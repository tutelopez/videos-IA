# Carpeta de Audio

Coloca aquí tus archivos de audio para el reel:
- `voz.mp3` o `voiceover.mp3`: La narración de la historia bíblica.
- `musica.mp3` o `ambient.mp3`: Música de fondo (instrumental, solemne o épica).

Para activarlos en el video, simplemente descomenta la línea `<Audio src={staticFile("audio/musica.mp3")} />` en `src/Composition.tsx`.
